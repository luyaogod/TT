看一次上传，先认三样东西

① 型态（.tab 里的 assembly type）② 模板（mdl/code_*.template + slice/*）③ 加点（.tap）。缺一样，代码就不对。

改前端规格后为什么必须重产

规格 → .tab → 型态/骨架可能变；直接手改 .4gl 的生成段，下次重产必被覆盖。客制逻辑写进 add-point 才留得住。

为什么会出现空列的 SQL

r.t 缺 FK（或设计器 tables.xml 过期）→ .tab 里关联为空 → 生成的 JOIN 出现 AND  = xmdducseq 这种半截条件。
