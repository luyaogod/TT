# internal/skill — 技能（官方 + 第三方）的唯一实现

「技能」这件事的实现都在这儿：frontmatter 的解析与合规判定、两套来源的扫描与冲突判定、
装到 agent 目录的复制与改写。

**纯管线**：不读配置、不打印、不碰 cobra。来源目录由调用方给（官方传 `<exe 目录>\skills`，
第三方传登记表里的路径），目标目录由调用方给，告警作为返回值带出去。

为什么单独成包：这套逻辑原来长在 `internal/cli/install.go` 里，只有命令行一个调用方。
现在设置页也要「列出有哪些技能、哪个失联、装到哪儿」，而它拿不到 `internal/cli`
（那里全是 cobra）。同一份判定必须两处一致 —— 尤其「什么算合规」和「名字撞了谁赢」，
两处各写一遍就会养出两套口径。

## 两套来源

| 来源 | 从哪来 | 坏掉时 |
|---|---|---|
| 官方 `OriginOfficial` | `<exe 目录>\skills`，随包发布，走专用路径 | **硬失败**：那是发版包坏了，不是用户配错了 |
| 第三方 `OriginExternal` | `config.json` 的 `skills.externals`，一行一个技能目录 | 告警 + 跳过，其余照装 |

第三方的三种失败（`State`）：`missing` 路径不存在、`invalid` 没 SKILL.md 或 frontmatter
不合规、`conflict` 与官方或先登记的第三方同名。

冲突规则：**官方优先**；两条第三方同名时**先登记的那条**优先（顺序写在配置里，可审）。

## 装的时候发生了什么

`BuildPlan` 只算不写（`--dry-run` / 设置页的「只算不装」就是只跑它）；`Apply` 才落盘。

- 目标已有同名条目：默认**跳过**（追加模式，让多个来源共用 `.agents/skills`），
  `Force` 才删掉重装。只动「名字在计划里」的顶层条目，目标里的其它内容一律保留。
- 技能目录复制时**只跳过根级 `assets/`**；嵌套的同名目录照装（它不是静态资源约定）。
  不做通用 ignore 语法 —— 那会让「为什么这个文件没装进去」变成要读文档才能回答的问题。

## assets 指针（`assets.go`）

第三方技能根级 `assets/` 不复制，改为在目标 `SKILL.md` 的正文首行写一行：

```
> 静态文件位置：D:\my-skills\kb-faq\assets（未复制到本目录，请按此路径读取）
```

- 哨兵前缀 `> 静态文件位置：`。安装时先找这一行：找到就**替换**，找不到才插入 ——
  `--force` 刷多次也只有一行，源路径变了还会自动纠正。
- 只做字节级插入/替换：BOM、原文换行风格（CRLF/LF）、frontmatter 全部一个字节不动。
- `assets/` 不存在或里面一个文件都没有（`HasAssets`）→ 完全不动 `SKILL.md`。

## 四条已知取舍（别当成 bug）

1. **目标里的 `SKILL.md` 与源文件故意不一致**（多了那行指针）。所以漂移只能靠数据目录里
   `.tt-skills.json` 的版本戳判断，不能拿源/目标 diff 判。
2. **指针是绝对路径**：换机器、挪目录即失效，下次安装会再告警一次。
3. **沙箱严格的 agent 可能读不到工程目录外的绝对路径**。那时只能由用户自己把资源挪进工程；
   本轮不做 copy / junction 两种模式（见计划 `tt-skill-plan.md` 的「非目标」）。
4. 知识库型技能装完，目标目录里只有几 KB 的 markdown —— 这是这套设计的目地，不是漏了。

## 判据

```bash
go test ./internal/skill -count=1
```

覆盖：frontmatter 的各种合法/不合法写法、指针注入的 BOM/CRLF/幂等/换路径、
根级 assets 跳过而嵌套不跳、官方不合规硬失败、第三方三类告警、同名两个方向、
`--force` 幂等、dry-run 不建目录、目标与源相同被拒。

## 改动影响面

| 改什么 | 会波及 |
|---|---|
| `ValidateMeta` | 官方技能会被拒绝发版；第三方会在安装时被跳过 |
| 冲突规则 | 「机器上跑的是谁的技能」—— 改错会让第三方顶掉官方手册 |
| `InjectAssetsPointer` | 所有带 assets 的技能的目标 SKILL.md；哨兵换了旧指针会变成两行 |
| `Apply` 的跳过/覆盖语义 | 用户目录里已有的技能会不会被冲掉 |
