# internal/dict/server — 字典侧的两个长跑动作

只提供两个动作的接口：**源码镜像拉取**与**字典同步**。没有别的。

**它们不对应一个独立页面**：这两个动作是统一设置页「数据字典」分区里的两张卡片，
所以本包的端点直接挂在共享层 `/api/*` 下，不加挂载前缀。包保留成独立结构，
是因为它持有这两个长跑任务的状态与处理器 —— 与"页面挂在哪"无关。

对外只暴露两个东西：构造函数与 `Handler()`；挂载方（统一服务）把它直接挂在共享层。
凡是两个工具都要的端点（环境与库的读写、探测、健康检查）由统一层各提供一份，本包不重复。
