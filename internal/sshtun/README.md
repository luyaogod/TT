# internal/sshtun — SSH 端口转发隧道

本地监听一个 TCP 端口，把连接经 SSH 转发到远端的 `host:port`。

**用在哪**：客户端的机器到不了数据库，但那台库对 SSH 服务器（或与它同网）是可达的。
这时先起一条隧道，客户端驱动仍然按"直连"的方式连 `127.0.0.1:<本地端口>`，
**驱动层不需要知道隧道存在**。

**只服务客户端直连那条线。** 服务器侧本来就连着服务器，隧道对它没有意义 ——
给服务器侧加隧道支持是错误的方向。

## 判据

本包没有自己的测试文件；行为由字典线的用例与其隧道路径覆盖。
