# internal/dbconfig — 数据库连接模型

配置文件里"库"那一节的类型定义：类型 / 主机 / 端口 / 服务名（Oracle）或库名（金仓）、
账号清单、只读开关、可选的隧道配置。

## 三条约定

- **每个环境一对一挂一个库**：库是环境级的，不是企业级的（企业编号只决定用哪个账号）。
- **账号清单是列表，运行时用哪个由企业编号决定**：
  - 服务器侧：拿解析出来的账号名在清单里查密码，未收录则回退"账号 = 密码"的惯例；
  - 客户端直连（探测 / 在线查询 / 同步）：与企业编号无关，取列表首项。
- **服务器侧执行工具的路径一律自动探测，不存进配置** —— 登录后现取，避免配置文件在不同机器上
  指向不同路径。

## 入口

| 入口 | 作用 |
|---|---|
| `Connection` | 一个环境的库连接（含账号清单与只读开关） |
| `DialCred` | 客户端直连该用哪个账号与口令 |
| `ReadonlySQLEnabled` | 该环境是否启用只读语句守卫（缺省启用） |
| `target.go` | 把"一次查询实际落在哪"升成一等公民（谁连的 / 连到哪 / 哪个账号 / 怎么定下来的） |
