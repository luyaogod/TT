# internal/entdir — 企业目录（与传输无关的那一半）

企业编号 → 账号的解析结果，以及它的落盘快照。**只放与传输无关的部分** ——
怎么连服务器、怎么在库上查那张映射表，由调用方注入，因为两条路径的传输方式本来就不同：

| 路径 | 怎么查 |
|---|---|
| 调试线（服务器侧） | 借服务器上的库客户端，SSH exec + 标准输入 |
| 字典线（客户端直连） | 客户端驱动直连，可选走 SSH 隧道 |

但两边读的是**同一张映射表**、写的是**同一个快照文件**。这个包存在的意义就是让它们对
"企业 99 是哪个账号"必须给出同一个答案：**文件名、指纹、新鲜期、序列化格式全部只有一份定义**，
任何一边改了另一边自动跟上。

> **"企业 → 数据库"这个说法不准。** 库是**环境级**的（一个环境一对一挂一个库），
> 企业编号只决定用这个库里的哪个账号（schema）。所以解析出来的永远是**账号**。

## 快照

| 入口 | 作用 |
|---|---|
| `DBIdent(dialect, host, port, svc)` | 库的身份串（同一个库换环境也应认出是同一个库） |
| `Fingerprint(sshHost, sshUser, zone, dbIdent)` | 环境指纹：这四项任一变了，快照作废 |
| `EnvSeg` / `Path` / `PathSafeSeg` | 快照文件名与路径（按环境分段） |
| `Read(path, fingerprint)` | 读快照 |
| `Write(path, s)` | 原子落盘 |
| `Snapshot` / `Mapping` | 快照结构与映射项 |

**读的规则很硬**：不存在、坏掉、版本不符、**指纹不符**、映射为空 —— 一律当作"没有"。

**它不判过期。** 新鲜期只由调用方按 `FetchedAt` 判断 —— 过期的快照在"现查失败"时是**唯一的
答案来源**，用不用由调用方决定。

**快照是可丢弃的缓存，不是数据源**：读坏了、写不出一律当没有，绝不因此报错。

## 判据

```bash
go test ./internal/entdir -count=1
```

**覆盖**：指纹的四个组成部分**每一个**都必须影响它（换机器 / 换区域 / 换库 = 换了另一份
`gzou_t`）、没有库时那一格是字面量 `none`、`EnvSeg` 的回退链（环境名 → 主机-区域 →
主机 → `_`）、`PathSafeSeg` 挡掉 `..`、快照往返（`Placeholder` 标记必须保住）、
**`Read` 的每一条拒绝理由**，以及**它故意不判过期**这一点。

三条容易读错的，都单独钉了：
- **`Read` 不判过期**（远离新鲜期 100 倍的快照照样读得出来）—— 过期快照在"现查失败"时
  是唯一的答案来源，用不用由调用方按 TTL 定。
- **`Write` 在 `dataDir` 为空时报错**，而 `saveBPs` 那种"没开持久化就静默跳过"不同。
- 快照**不落临时文件**（原子写走"临时文件 → Rename"，落盘后目录里只剩快照本身）。

**故意不覆盖**：真去服务器/真库上查 `gzou_t`（属 L4）。它的行为此前一直被
`internal/debug` 那侧的包装（`pathSafeSeg` / `entFingerprint` / `entSnapshotPath`）
间接跑到 —— 那些测的是**接线**，本包的测试补的是接线测不到的契约。
