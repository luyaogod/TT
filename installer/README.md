# installer — 用户级安装包

`tt.wxs` 是安装包定义，`icon.ico` 是它用的图标。

## 为什么是"用户级"

- **装到用户目录**，不碰 `Program Files` —— **全程不需要管理员**。这与工具一贯的取向一致：
  把 tt 加进 PATH 也只写用户级环境变量、绝不碰系统 PATH。
- **PATH 写在用户级**，卸载时由安装包自己摘掉。
- **装完不写便携标记**：配置该落在用户配置目录（用户可写），而不是程序目录（普通用户写不进去）。
  装着便携标记的便携包与装着这套规则的用户级安装，是两种不同的布局。

## 只管四件事

产品、目录、PATH、升级关系。**文件清单不在这里** —— 它由采集工具从暂存目录生成，
所以技能增减、引擎文件变化都不需要改这个文件。

卸载时要删的目录是另一处补的（见 [../tools/README.md](../tools/README.md)）。

## 判据

```bash
build_msi.bat        # → dist/TT-<版本>-x64.msi
```

装一次、卸一次，确认：不需要管理员、PATH 被加上又被摘掉、程序目录被清干净、
配置落在用户配置目录而不是程序目录。
